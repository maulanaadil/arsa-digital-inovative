This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Setup

First run to copy .env.example to your .env

```
cp .env.example .env
```

For the credentials you can check on [this page](https://github.com/maulanaadil/arsa-digital-inovative/wiki/Credentials).

Install the depedencies

```
npm install

yarn install

pnpm install
```

### Optional

suggested to install nvm first then run

```
npm preinstall

yarn preintall

pnpm preintall
```

to set node version is same as author.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/basic-features/font-optimization) to automatically optimize and load Inter, a custom Google Font.
